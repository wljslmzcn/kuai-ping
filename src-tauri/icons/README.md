# 图标说明

Tauri需要以下尺寸的PNG图标：

- `32x32.png` - 32x32像素
- `128x128.png` - 128x128像素
- `128x128@2x.png` - 256x256像素 (Retina)
- `icon.icns` - macOS图标
- `icon.ico` - Windows图标

## 生成图标

可以使用以下工具生成图标：

1. [Tauri Icon Generator](https://tauri.app/v1/guides/features/icons)
2. [Icon Kitchen](https://icon.kitchen/)

## 快速生成步骤

1. 准备一个1024x1024的PNG源图
2. 访问 https://tauri.app/v1/guides/features/icons
3. 上传源图并下载生成的图标包
4. 将生成的图标文件放入此目录
